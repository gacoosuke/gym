# Souvenirs physiques

Album photo privé partagé par Ali, Zakaria et Idrissa. Les photos originales sont conservées dans un bucket R2 privé et les métadonnées dans D1. Les dates de prise — corrigibles à l’import — alimentent les galeries, le calendrier perpétuel et le comparateur.
